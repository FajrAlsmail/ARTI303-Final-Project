# Project Report outline (final format: PDF)

1. Cover: project title, course, team members.
2. Introduction, problem, target users, user requirements and objectives (student 4, with leader).
3. Existing solutions / brief market comparison (student 4, with leader).
4. Dataset/source URL, license/ethical limits, data cleaning and validation (student 1).
5. Data workflow, EDA, transformations, exported outputs, visualizations (student 2; student 1 for cleaning).
6. System design and architecture (student 5).
7. AI approach, NLP/embedding method, baseline, evaluation results, limitations (student 3).
8. Streamlit screenshots, results, input validation (student 4).
9. Testing, reproducibility, failure cases, setup instructions (student 5; each student contributes tests).
10. Limitations and potential future work (all; consolidate with student 3).
11. Conclusion, references, individual member contributions (all; leader consolidates).

Use evidence from actual running code. Do not claim optional features are implemented unless tested. Include all required citation details.
